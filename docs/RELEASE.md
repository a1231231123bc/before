## Store metadata workflow

`store.config.json` contains only public metadata and screenshot paths. `store.config.js` optionally adds review contact details from ignored `store.private.json`, plus [review notes](APP-REVIEW-NOTES.txt).

Keep `store.private.json` readable only by the local user. It contains `firstName`, `lastName`, `email` and `phone`. Never commit review phone numbers, Apple credentials, signing keys, authentication sessions or metadata pulls containing private contacts. Without this file, pushing metadata leaves existing review contact details unchanged.

Using Node 24:

```sh
npx eas-cli@latest metadata:push --profile production --non-interactive
```

Screenshots are original simulator captures, not resized browser images. Their display types are `APP_IPHONE_61` and `APP_IPAD_PRO_3GEN_129`. When replacing images, verify the upload and processing status in App Store Connect.

The public pages deploy from `site/` through `.github/workflows/pages.yml`. Keep their privacy and support statements consistent with the released binary.

## Builds and TestFlight

The production profile uses EAS cloud builds, Node 24.4.1, the `sdk-57` iOS image and remotely incremented build numbers. The offline video renderer is regenerated by `postinstall` on the build server. Credentials are managed by EAS.

```sh
npx eas-cli@latest build --platform ios --profile production
npx eas-cli@latest submit --platform ios --profile production --id <successful-build-id> --groups 'Team (Expo)'
```

Always submit the exact successful build ID. Uploading with EAS Submit does not submit public App Review or publish the app. Wait for Apple processing, verify the version/build number and add it to the internal testing group.

## Product limitations and future checks

The journal stores photos and notes on the device without accounts, a backend, analytics, advertising or cloud sync. Removing the app can remove the journal. Exported images and videos are not a full journal backup; this is disclosed in the app, description and support page.

The first release includes photo capture/import, optional notes and categories, timelines, a before/after slider, still-image export and six-second 1080 × 1920 MP4 export.

Before expanding support, check physical-device permission denial and limited access, HEIC/large photos, low storage, interrupted exports, share cancellation, accessibility, reduced motion and older-device performance. Complete journal backup/import, Russian localization, dark mode and Android distribution remain separate work.
